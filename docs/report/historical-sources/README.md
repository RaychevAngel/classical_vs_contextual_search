# Original manuscript source evidence

Recovered from the original Overleaf projects on 23 October 2026. The TeX and bibliography files below preserve the exact downloaded bytes; only `report.tex` is a standardized filename.

These are **archival sources for the numerical tables, recipes and original narrative**, not alternative current PDFs or separate recommended build targets. Read the [single consolidated report](https://angelraychev.com/research/explicit-learned-search/explicit-versus-learned-search.pdf) for the current methods-and-results account. Its complete build source is one directory above this archive. The original manuscripts can contain imprecise wording that the consolidated account clarifies; preservation is not endorsement of every old interpretation.

- **CS224N:** *Size Doesn't Matter If You Search Enough*. Yalcin Tur, Mihajlo Stojkovic, Angel Raychev. Mentors: Anjiang Wei and Rafael Rafailov. Overleaf original paths: `template/template.tex`, `template/references.bib`.
- **CS224R:** *In-context Search: Efficiency Boost or Fundamentally New Capability?* Angel Raychev, Yalcin Tur, Mihajlo Stojkovic. Overleaf original paths: `cs224r_final_report_2025.tex`, `reference.bib`.

Original figure assets and the mapping to their original names are preserved in [`../figures/`](../figures/). The course style packages are not duplicated here; this directory is not an independent original-project build archive. The unmodified original downloads are also retained privately by Angel.
